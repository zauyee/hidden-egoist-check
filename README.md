# hidden-egoist-check · 初见识人把关

> 刚认识的商业伙伴，表面体面、热情、有格局——底下是不是纯利己的投机者？聊一场就能判。

## 这是什么

一个帮你在"跟刚认识的商业伙伴初次交谈"时做判断的 AI 技能（Skill）。

适用场景：饭局、商务拜访、会议茶歇、展会、有人引荐的第一次见面。一般 15 分钟到 1 小时的单聊，凭对方的语言内容、提问方向、行为闭环、肢体眼神语调，判断他是不是"隐藏型利己者"（表面体面热情有格局，底下是纯利己的投机者），并给出交往档位：**深交 / 浅层往来 / 不往来**。

## 它解决什么问题

识人这件事，感觉靠不住：越舒服的谈话越要过一遍硬指标，不舒服的谈话未必危险。这个 Skill 用一套固定标准代替感觉。

**一票否决类（命中任意一条，深交免谈）：**

1. **非对称合作条件**——他出背书、资源、人脉这类名义资产，要你垫钱、出力、出核心资产。失败他毫发无损，成功他分大头
2. **答应的事不兑现**——承诺了交付时间，过了没给、也不主动说明。言行割裂是最硬的测谎指标
3. **问题直插核心资产**——初次单聊就问客户名单、客单价、独家打法、现有合作方。真撮合者初次只问服务边界和交付能力
4. **具体合作滑开**——问两次"具体怎么合作"都滑开（"见面聊、见面聊"）。手里没盘子，约你是为了套底牌
5. **顺杆爬推销**——你刚露出点需求，立刻接"我们家就能做，加个微信"
6. **尊卑话术**——把合作包装成"前辈的考验""年轻人得先证明自己"
7. **恩情锚定**——整场提"我帮过谁"超过三次，被帮的人还都比你体面

**加分类（命中往上调档）：**

8. 直接给微观硬参数：产能、良率、价格区间、起订量、具体路径
9. 零隐私打探：不问团队多大、跟谁合作、客户是谁，只谈事本身
10. 言出必行：当场兑现，或说好明天发就明天发
11. 明码标价的对等交换："你把数据发我，我帮你看看结构"

**软判断（要结合情况看）：** 复述你说过的话之后接不接疑问和卡点、失败史讲得坦白要跟合作条件对照、模糊词约饭有没有议题跟上、眼神语调当佐证不当主证、相处舒服程度反着用。

**一个前提原则：** 判错的代价不对等——漏判的代价（感情欺骗、金钱损失、口碑损失、时间浪费）远大于错防。所以整套标准偏严：**宁可错防，不可错信。**

## 怎么安装

1. **把整个 Skill 文件夹下载下来**（不要只下载 SKILL.md 一个文件）。
2. 把文件夹放进你的 AI 工具的 Skill 目录。
3. 不同 AI 工具目录不一样，**不知道放哪儿，就直接问你的 AI 工具："Skill 文件夹应该放在哪里？"** 它会告诉你正确位置。
4. 放好后刷新或重启对话，Skill 就生效了。

## 怎么使用

不需要记命令，说出这类话，AI 会自动调用这个 Skill：

- "帮我判一下这个人能不能深交"
- "这人是不是孙宇晨那类的"
- "帮我判断这个商业伙伴靠不靠谱"
- "初见的这位怎么定档"

然后把现场情况描述出来：对方说了什么原话、问过你哪些问题、答应过什么、兑现了没有、合作条件怎么谈的。描述越细，判得越准。

它会按固定格式回你：

```
1. 结论：深交 / 浅层往来 / 不往来 / 拿不准
2. 理由：命中了哪几条标准，逐条对着说
3. 下一步打法：深交怎么推进、浅层怎么防守、不往来怎么收场
4. 拿不准时直接说拿不准，并告诉你还缺什么信息
```

## 输出示例

问：行业峰会上认识一位前辈级创始人，当场打电话帮我问清了资质路径，聊天坦白讲早年赔钱的经历。但他提了四五次"当年我拉了 XX 一把"，谈合作时说：他出资源和背书，我来干活，前期成本我全垫，"年轻人得先证明自己"。这人能深交吗？

答：
- 结论：浅层往来（单次互惠型）——深交免谈，不必绝交
- 理由：命中一票否决两条——非对称合作条件（他用背书这类名义资产对赌我垫钱出力的实体资产，失败他毫发无损，成功他凭背书分大头）+ 尊卑话术（把利益博弈包装成前辈的恩赐）；"我帮过谁"提了四五次，超过三次，属恩情锚定、服从性测试；当场帮实忙是真实的，但对他成本极低，专打亏欠感，不构成深交依据；讲失败史坦白可能是真敞亮，但对照合作条件，更像假性暴露卸防术
- 下一步打法：那个电话的人情当场还清（致谢、送礼、平账），垫资项目坚决不接；保留联系，只接信息，绝不出让核心资产
